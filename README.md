# Betting 135
This application is a work in progress and pulls real time sports betting odds from Draft Kings, Fanduel, and BetMGM.  It is pulling mock data by default since the sports odds API has a limited amount of requests per month.

## Setup

Make sure to install dependencies:

```bash
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

## Production

Build the application for production:

```bash
npm run build
```
